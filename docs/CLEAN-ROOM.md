# Nota de origem (clean room)

Este projeto **não contém código, recursos, textos, ícones, nome ou marca** de nenhum
desfragmentador comercial. O que foi aproveitado da análise de um instalador existente
(veja `ANALYSIS.md`) foi apenas a **lista de funcionalidades observáveis** (análise, desfragmentação
completa/rápida/espaço livre, pasta/arquivo, mover arquivos grandes para o fim, SSD, agendamento,
condições de execução, CLI), que são ideias e não conteúdo protegido.

Toda a implementação foi escrita do zero a partir da documentação pública da Microsoft sobre
desfragmentação de arquivos. Não foram copiados trechos decompilados, strings de interface,
URLs de serviços de terceiros nem qualquer mecanismo de ofertas/telemetria.
O app **não** inclui adware, ofertas de terceiros, verificação de licença nem telemetria.
